# build-in-public

Contenido para publicar sobre la construcción de predicts. Nada de esta carpeta se publica solo:
todo es borrador hasta que Héctor lo revisa y lo sube.

- `ESTRATEGIA.md`: objetivo, reglas, canales, calendario de episodios y flujo de producción.
- `diario/`: una entrada por día de trabajo (decisiones, mediciones, errores). Es la fuente de todo.
- `episodios/NN-slug/`: borradores por episodio (LinkedIn pt/es, carrusel, Reddit, artículo).
- `publicaciones.md`: registro de lo publicado (fecha, canal, link, métricas).
